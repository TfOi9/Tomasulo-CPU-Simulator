# Tomasulo-CPU-Simulator

## 项目介绍

本仓库实现了基于 Tomasulo 算法的五级流水线式乱序执行 CPU 模拟器，使用 C++ 语言实现。在每个 CPU 时钟周期内，模拟器将会完成取指 `fetch`、发射 `issue`、执行 `execute`、写回 `writeback` 和提交 `commit` 五个步骤，顺序可以交换。此外，还实现了顺序执行的解释器，用于正确性基线和对拍测试。

## 项目架构

这一 CPU 模拟器由多个部件组成：
- 模拟内存 `SimMemory`: 大小固定为 1MB，用静态数组模拟内存。
- 指令内存 `InstrMemory` 和数据内存 `DataMemory`。
- 解析器 `Decoder`: 用于解析输入为具体命令。
- 运算器 `ALU`，当前实现仅为一计算函数。
- 保留站 `ALURS` 和 `LSRS`，分别用于 ALU 计算任务和内存操作的临时保存，各有 8 个槽位。
- 重排缓冲区 `ReorderBuf` ROB: 重排乱序执行的指令，按序提交。
- 寄存器堆 `ArchRegFile`: 含有 32 个模拟寄存器。
- 寄存器重命名表 `RegAliasTab` RAT。
- 通用数据总线 `CDB`: 用于数据广播，仅有一根。
- 分支预测器 `BranchPred`: 预测分支并投机执行。
- 存储器缓冲 `StoreBuf`: 用于解决内存读写冲突。
- 调试器 `TraceFile`: 用于打印各时钟周期的寄存器值，用于调试。
